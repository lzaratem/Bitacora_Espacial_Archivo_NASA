# ACTA DE BRIEFING

Los abajo firmantes acuerdan que el proyecto Bitácora Espacial Archivo NASA tiene el siguiente alcance para su primera versión:

__Se construirá:__

1.	Buscador e integración con la API pública de la NASA (q=nebula&media_type=image).
2.	Galería responsive con tarjetas formateadas (Título, fecha, centro, tags y thumbnail).
3.	Sistema de optimización de carga (Lazy loading + thumbnails reducidos).
4.	Componente de truncado de descripción ("Leer más" / Modal de detalle).
5.	Filtro dinámico por centro de investigación o palabras clave.

__No se construirá:__
1.	Sistema de inicio de sesión o usuarios.
2.	Galería de descargas en alta definición masiva.
3.	Reproducción de elementos multimedia distintos a imágenes.

El usuario objetivo es: Estudiantes y aficionados a la astronomía que navegan desde dispositivos móviles o de escritorio.

El criterio de éxito es: Carga ágil de la interfaz visual (< 2 segundos) con lectura clara de metadatos y navegación fluida.

Cualquier cambio de alcance posterior a esta acta requiere acuerdo escrito de ambas partes.
